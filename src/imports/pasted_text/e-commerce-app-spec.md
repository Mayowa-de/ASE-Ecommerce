DOMAIN:
adeolaspiritualstore.com.ng

============================================================
PROJECT PURPOSE
============================================================

Build a complete, polished and functional e-commerce web application
for Adeola Spiritual Enterprises.

This is intended to become the visual and functional foundation for a
real production website that will later be adapted to WordPress/Elementor/
WooCommerce using a suitable migration/conversion workflow such as Figmentor.

Do NOT treat this as a static visual mockup.

Build a complete connected frontend experience with:
- working navigation
- realistic product data
- product variants
- search
- filtering
- favorites
- cart
- customer accounts
- checkout
- orders
- reviews
- admin management screens
- editable homepage content
- responsive desktop/tablet/mobile layouts

Where real backend services are not available, use realistic mock/local
data and state persistence so the prototype behaves like a real store.

Do NOT implement real payment processing, real WooCommerce APIs, production
authentication servers or production databases unless the environment
already supports them.

The application structure must nevertheless be clean and data-driven so
the frontend can later be connected to WordPress/WooCommerce.
